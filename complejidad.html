¿Qué mide la Notación Big O?

Evalúa la tasa de crecimiento del tiempo de ejecución o consumo de memoria RAM conforme el volumen de datos de entrada N tiende al infinito. Se enfoca en el peor escenario posible (Worst Case) para garantizar cotas superiores fiables de rendimiento.

Clasificación y Categorías de Algoritmos

En el desarrollo de software profesional, los algoritmos se clasifican según su modelo mental y estrategia de resolución. Seleccionar la categoría adecuada determina la escalabilidad y consumo de memoria de cualquier solución en producción.

Algoritmos de Búsqueda

Paradigma de Localización
O(log n)

Reducen sistemáticamente el espacio de búsqueda descartando mitades completas de datos donde la solución no puede encontrarse.

Ejemplos: Búsqueda Binaria, Ternaria y Exponencial.

En producción: Índices B-Tree en bases de datos y git bisect.

Algoritmos de Ordenamiento

Reorganización de Memoria
O(n log n)

Disponen los elementos en secuencia estrictamente monótona, facilitando búsquedas instantáneas y agregación eficiente.

Ejemplos: QuickSort, MergeSort, HeapSort y TimSort.

En producción: Cláusulas ORDER BY en SQL y feeds en redes sociales.

Grafos y Enrutamiento

Redes y Topología
O(V + E)

Modelan entidades conectadas para calcular trayectos mínimos, componentes conexas y dependencias de ejecución.

Ejemplos: Dijkstra, BFS, DFS y Algoritmo A*.

En producción: Navegación en Google Maps y enrutamiento IP (OSPF).

Programación Dinámica

Optimización & Memoización
O(n · W)

Descompone problemas complejos en subproblemas superpuestos y memoriza sus soluciones para erradicar el recálculo exponencial.

Ejemplos: Problema de la Mochila (Knapsack), LCS y Levenshtein.

En producción: Diferencias de código en git diff y alineación de ADN.

Hashing y Criptografía

Dispersión y Acceso Directo
O(1)

Transforman llaves arbitrarias en direcciones de memoria contiguas para ofrecer consultas y verificaciones en tiempo constante.

Ejemplos: Tablas Hash, SHA-256, HMAC y Bloom Filters.

En producción: Caché distribuida (Redis/Memcached) y validación en Blockchain.

Divide y Vencerás

Partición Recursiva
O(n log n)

Fragmenta la entrada en subproblemas disjuntos recursivos, resuelve cada uno y recombina los resultados sin solapamiento.

Ejemplos: MergeSort, Multiplicación Karatsuba y FFT.

En producción: Compresión de audio/imagen (MP3, JPEG) y renderizado 3D.

Implementaciones de Algoritmos en Código

¿Cómo analizar el código de un algoritmo?

Presta atención al avance de los punteros índice, la condición de invariante de bucle y el número de comparaciones ejecutadas. Selecciona tu lenguaje de programación preferido:

1. Algoritmo de Búsqueda Binaria O(log n)

JavaScript ES6 — Búsqueda Binaria
// Búsqueda Binaria en JavaScript ES6 - Complejidad O(log n)
function busquedaBinaria(arreglo, objetivo) {
    let inicio = 0;
    let fin = arreglo.length - 1;

    while (inicio <= fin) {
        let medio = Math.floor((inicio + fin) / 2);

        if (arreglo[medio] === objetivo) {
            return medio; // Localizado en índice medio
        }
        if (arreglo[medio] < objetivo) {
            inicio = medio + 1; // Descartar mitad izquierda
        } else {
            fin = medio - 1;    // Descartar mitad derecha
        }
    }
    return -1; // Elemento no presente
}

2. Algoritmo de Ordenamiento por Burbuja O(n²)

JavaScript ES6 — Ordenamiento por Burbuja
// Ordenamiento por Burbuja en JavaScript ES6 - Complejidad O(n²)
function ordenamientoBurbuja(arreglo) {
    let n = arreglo.length;
    for (let i = 0; i < n - 1; i++) {
        for (let j = 0; j < n - i - 1; j++) {
            if (arreglo[j] > arreglo[j + 1]) {
                // Intercambio de valores adyacentes
                let temporal = arreglo[j];
                arreglo[j] = arreglo[j + 1];
                arreglo[j + 1] = temporal;
            }
        }
    }
    return arreglo;
}
